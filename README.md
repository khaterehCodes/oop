# 🧩 Object-Oriented Programming

A programming project focused on practicing and understanding the core concepts of **Object-Oriented Programming (OOP)**.

The project was created to strengthen fundamental programming concepts such as classes, objects, encapsulation, inheritance, polymorphism, and abstraction through practical implementation.

---

## 🎯 Project Overview

This repository contains practical exercises and implementations focused on **Object-Oriented Programming principles**.

The main goal of the project is to understand how object-oriented concepts can be used to structure code into reusable, organized, and maintainable components.

## 📚 OOP Principles

### Encapsulation

Keeping data and the methods that operate on that data together while controlling access to the internal state of an object.

### Inheritance

Creating new classes based on existing classes to reuse and extend their functionality.

### Polymorphism

Allowing objects with different implementations to be treated through a common interface or abstraction.

### Abstraction

Hiding unnecessary implementation details and exposing only the essential behavior of an object.
